# Halmos symbolic checks (2026-10-29)

Tool: halmos 0.3.3 (free, a16z), `cd contracts && halmos --contract FundingSymbolic`. File:
`contracts/test/halmos/FundingSymbolic.t.sol` (`check_*` functions; `forge test` ignores them).

| Property | Result |
|---|---|
| `Funding.stepAtRate`: every early-exit branch (dt 0, rate 0, norm at the floor, exponent past e^-42) leaves the norm unchanged or sets exactly the floor, for every input | **Proved** (14 paths) |
| `FixedMath.expWad(x) == 0` for every x below -42e18 | **Proved** |
| `Funding.rate <= 1e18`; `rate == 0` iff V > 0 and payoff >= V; rate monotone in payoff; the step's final mulDiv never grows the norm or crosses the floor | **Not proved**: the solver timed out at 600 s per query (OpenZeppelin's 512-bit `mulDiv`), even with prices bounded below 2^96. These remain covered by fuzz and invariant tests |
| exp / ln series accuracy | Out of reach for symbolic execution (data-dependent loops); covered by the R1/R7/R9 reference vectors and fuzz tests |

Honest summary: a first formal layer on the funding step's branches, not a full proof of the pricing maths.
